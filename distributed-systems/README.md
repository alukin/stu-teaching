# Розподілені системи / Distributed Systems

Курс присвячений принципам побудови та реалізації розподілених програмних систем: комунікаціям, координації, узгодженості, відмовостійкості й сучасним платформам.

## Матеріали

- `lectures/` — лекції (будуть додані поступово).
- `labs/` — лабораторні роботи.
- `resources/` — додаткові матеріали та посилання (будуть додані поступово).

## Лабораторні роботи

- **[Лабораторна робота №5 — Дослідження принципів технології Blockchain](labs/lab-05-blockchain/README.md)** — методичні вказівки та Java-приклад доступні.
- **[Лабораторна робота №6 — Транзакції, цифрові підписи та блоки](labs/lab-06-blockchain-transactions/README.md)** — навчальна реалізація з Maven і завдання для дослідження.
- **[Лабораторна робота №7 — Розподілений Blockchain: P2P-мережа та консенсус](labs/lab-07-distributed-blockchain/README.md)** — три вузли Quarkus, WebSocket, Jackson, консольний клієнт, синхронізація та forks.

Попередні лабораторні роботи будуть додані зі збереженням нумерації навчальної програми.
