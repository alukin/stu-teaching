# Навчальні матеріали / Teaching Materials

Навчальні матеріали з дисциплін, які викладає **Олексій Лукін (Oleksiy Lukin)** у [Національному університеті «Чернігівська політехніка»](https://stu.cn.ua/), Україна.

Репозиторій містить лекції, методичні вказівки до лабораторних робіт, приклади програмного коду, практичні завдання та додаткові матеріали для самостійного вивчення.

Мета — допомогти студентам не лише засвоїти теоретичні основи сучасних інформаційних технологій, а й отримати практичний досвід дослідження, розробки та використання програмних систем.

Матеріали доповнюються поступово.

## Навчальні курси

### 1. [Розподілені системи (Distributed Systems)](distributed-systems/README.md)

Архітектура та принципи побудови розподілених систем, мережеві комунікації, взаємодія компонентів, узгодженість даних, відмовостійкість і сучасні технології розподілених обчислень.

Курс міститиме лекції, лабораторні роботи та приклади використання відкритих програмних платформ.

- **[Лабораторна робота №5 — Дослідження принципів технології Blockchain](distributed-systems/labs/lab-05-blockchain/README.md)** — методичні вказівки та Java-приклад.
- Попередні лабораторні роботи й інші матеріали будуть додані поступово.

### 2. [Криптографічний захист програм і комунікацій (Cryptographic Protection of Software and Communications)](cryptographic-protection/README.md)

Криптографічні алгоритми та протоколи, захист інформації, автентифікація, цифрові підписи, захищені комунікації та практичне застосування криптографічних технологій у програмних системах.

Матеріали курсу будуть додані пізніше.

## Організація лабораторних робіт

Лабораторні роботи орієнтовані на практичне дослідження програмних систем і технологій. Залежно від теми вони можуть містити:

- Мету роботи й необхідні теоретичні відомості.
- Методичні вказівки та пояснення основних алгоритмів.
- Мінімальні працездатні приклади програмного коду.
- Експериментальні й дослідницькі завдання.
- Завдання для самостійного вивчення open-source проєктів.
- Контрольні запитання.

Особлива увага приділяється розумінню принципів роботи програм, проведенню експериментів, аналізу результатів і формуванню навичок самостійної роботи з відкритим програмним кодом.

## Робота з матеріалами

Матеріали доступні для перегляду безпосередньо на GitHub.

Для локальної роботи клонуйте репозиторій:

```bash
git clone https://github.com/alukin/stu-teaching.git
cd stu-teaching
```

Вимоги до програмного забезпечення та інструкції із запуску будуть наведені у відповідних лабораторних роботах.

## About this Repository

This repository contains educational materials for courses taught by **Oleksiy Lukin** at [Chernihiv Polytechnic National University](https://stu.cn.ua/), Ukraine.

It includes lecture notes, laboratory assignments, working source code examples, and supplementary learning resources. The courses emphasize experimentation, understanding software architecture and algorithms, and independent exploration of open-source software.
