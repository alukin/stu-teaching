# Криптографічний захист програм і комунікацій / Cryptographic Protection of Software and Communications

Курс охоплює криптографічні алгоритми та протоколи, захист програм, автентифікацію, цифрові підписи та захищені комунікації.

## Матеріали

- `lectures/` — лекції.
- `labs/` — лабораторні роботи.
- `resources/` — додаткові матеріали та посилання.

Матеріали курсу будуть додані поступово.
